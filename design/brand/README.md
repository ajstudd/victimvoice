# Victim Voice logo

Approved concept: two helping hands, selected by the product owner on 11 November 2026.

The master is `helping-hands-master.png`. It was extracted from the approved reference with the built-in imagegen tool, with a genuinely transparent background. The edit prompt and approval are recorded in `selection.json`. The original presentation board is retained as `selected-helping-hands-reference.png`.

Production exports:

- `public/brand/helping-hands.png`: 512px transparent mark; shared website and staff portal component.
- `app/icon.png`: 512px browser icon on warm ivory.
- `app/apple-icon.png`: 180px touch icon on warm ivory.
- `mobile/assets/helping-hands.png`: transparent mark for app headers and launch screen.
- `mobile/assets/brand-icon.png`: 1024px opaque launcher icon, 720px centred mark.
- `mobile/assets/brand-adaptive.png`: 1024px transparent Android foreground, 600px centred mark inside the adaptive mask safe area.

PNG exports were mechanically resized and padded using Sharp. Do not recreate the mark with a generic shield or redraw the hands. Functional safety, privacy and emergency-action icons remain separate from the brand.

The mobile launcher and launch screen require a new installed build. An OTA update cannot replace an existing Android launcher icon.
