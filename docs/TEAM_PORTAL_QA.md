# Team portal and authenticator setup — 10 November 2026

The team portal now uses a responsive workspace shell, searchable member directory, expandable review forms, dedicated invitations/attention/report views, real record counts, inline validation and explicit empty states. Team members retain application, availability and assignment acknowledgment controls. Account references are tucked into a copyable account menu rather than the main content. Mobile navigation exposes all management views without horizontal clipping; keyboard arrows/Home/End move between tabs. Existing role/consent/assignment/evidence checks remain enforced by the backend.

The shared web staff authenticator gate now displays the QR returned by Supabase enrollment as a local SVG data image. No external QR generator receives real setup secrets, and secrets are not logged, persisted or sent to analytics. Setup-key fallback is initially collapsed. The verification step accepts six digits and checks AAL2 before displaying staff content. Existing verified factors continue through the current-code challenge without being reset or re-enrolled.
