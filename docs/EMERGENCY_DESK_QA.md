# Emergency desk, invitation visibility and contact privacy — 10 November 2026

The emergency desk now follows the team workspace design: consistent navigation, a filtered request queue and scoped detail pane, explicit message-delivery states, responder coordination, a confirmation step for resolution, separate responder-review and service-area views, and an accurate push-availability banner. Mobile selected-request navigation exposes a Back to requests action; filters clear the old selection. Sensitive context is cleared on focus loss/account changes/read errors. Reviewed workforce status and agency scope constrain approval controls; backend permission checks remain authoritative. Boundary imports stay behind an editor, validate geometry type before submission and use a stable agency ID to avoid duplicate create requests when retried. No guessed boundaries or new operational coverage are introduced.

A created invitation now opens a focus-trapped dialog immediately, with Copy invitation code, manual sharing instructions and an explicit notice that no email/SMS was sent. It is no longer hidden below the invitation form. Codes still remain account-bound, one-use, expiring and only shown at creation.
